## About

Hi, I'm **Abdullah Al Sakib**, 17, from Dhaka. I build clean, responsive websites and web apps, and I'm working my way up to full-stack development — one project at a time.

I learn by building: I study a topic, then make something real with it. My first real product is **KeyVEX**, an offline password manager you can explore on GitHub.

## What's inside

- **Animated hero** — typing effect that cycles through what I do
- **About** — who I am, how I learn, and what's next
- **Skills** — HTML, CSS, JavaScript, Bootstrap, Tailwind, with real tech logos
- **Projects** — KeyVEX featured, with live site and GitHub links
- **Journey** — how I got here, in four steps
- **Contact** — a 3-field form plus my social links

Everything is animated on scroll, and the whole site is fully responsive — desktop and mobile.

## Tech stack

| | |
|---|---|
| Markup & style | HTML5, CSS3 |
| Interactivity | Plain JavaScript (no libraries) |
| Fonts | Space Grotesk, Inter, JetBrains Mono (Google Fonts) |
| Icons | Real SVG logos (Devicon, Simple Icons) |

No build step, no framework — just open it and it works.

## Project structure

```
index.html            — the whole page
css/style.css         — theme, layout, cards and animations
js/main.js            — typing line, scroll reveals, progress bar, header, contact form
images/               — portrait photo and tech/social logos (SVG)
```

## Run it

Open `index.html` in a browser — that's it. Or serve the folder with any static server:

```bash
npx serve .
```
