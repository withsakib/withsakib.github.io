# Abdullah Al Sakib — Portfolio

Personal portfolio website. Static site, no build step.

## Stack

- HTML, CSS, plain JavaScript (no libraries)
- Space Grotesk + Inter + JetBrains Mono (Google Fonts)

## Structure

- `index.html` — the whole page
- `css/style.css` — theme, layout, cards and animations
- `js/main.js` — typing line, scroll reveals, progress bar, header, active nav link, card glow, contact form
- `images/` — portrait photo and tech/social logos (SVG)

## Sections

Hero · About · Skills · Projects · Contact

## Run it

Open `index.html` in a browser, or serve the folder with any static server.
